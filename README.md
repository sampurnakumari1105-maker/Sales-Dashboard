# Sales Dashboard Project

## Project Overview

The Sales Dashboard is a Python-based data analysis project that analyzes sales data using Pandas and Matplotlib. It helps identify revenue, top-selling products, and monthly sales trends.

## Technologies Used

* Python
* Pandas
* Matplotlib
* CSV Dataset

## Features

* Total Revenue Calculation
* Total Orders Analysis
* Total Quantity Sold
* Average Order Value
* Top 5 Selling Products
* Monthly Revenue Analysis
* Bar Chart Visualization
* Line Chart Visualization
* Automatic Sales Insights

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install the required libraries.
4. Run the following command:

```bash
python sales_dashboard.py
```

## Output

The project generates:

* Sales statistics
* Top-selling product analysis
* Monthly revenue trends
* Bar chart
* Line chart
* Sales insights

## Conclusion

This project demonstrates how Python can be used for data analysis and visualization. It helps understand sales performance and identify important business trends.
